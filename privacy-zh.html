感谢您使用 AOD Volume（以下简称“本应用”），本应用由 Beak（以下简称“我们”）开发并在 Google Play 上发布。我们非常重视您的隐私和个人信息的保护。请您在使用本应用前仔细阅读以下隐私政策，了解我们如何收集、使用、存储和保护您的信息。

1. 我们收集的信息

本应用自身不会采集、存储、传输您的个人信息。您在应用中设置的内容（颜色、样式、尺寸、位置等）仅保存在您的设备本地。

本应用通过 Google AdMob 展示广告。为了投放和统计广告，Google Mobile Ads SDK 会自动处理部分数据，详见第 2 节。

2. 广告与第三方 SDK

本应用使用了 Google LLC 提供的以下第三方 SDK：

  • Google Mobile Ads SDK（AdMob）——用于在应用内展示横幅广告。
  • Google User Messaging Platform（UMP）——用于在法律法规要求的地区（例如欧洲经济区、英国、瑞士）征求并管理您的广告同意。

出于广告目的，上述 SDK 可能收集并处理以下数据：

  • 设备标识符，包括 Android 广告 ID（AD_ID）和应用集 ID（app set ID）；
  • IP 地址以及由此推断的大致（非精确）位置信息；
  • 设备与应用信息，例如设备型号、操作系统版本、语言、应用版本；
  • 广告交互数据（广告的请求、展示、浏览、点击情况）以及诊断数据。

这些数据用于展示广告（在您同意的情况下包括个性化广告）、衡量广告效果、识别欺诈与滥用行为，以及改进 Google 的广告服务。我们自身不会接收或存储这些数据。

在法律要求的地区，本应用会在请求任何广告之前征求您的同意。您可以随时在应用内（关于 → 隐私选项）更改或撤回同意，也可以通过 boybeak@gmail.com 联系我们。关于 Google 如何处理这些数据，请参考：

  • Google 隐私权政策：https://policies.google.com/privacy
  • Google 如何使用来自使用其服务的网站或应用的信息：https://policies.google.com/technologies/partner-sites
  • Google 广告与如何关闭个性化广告：https://policies.google.com/technologies/ads

您也可以随时在系统设置中重置或删除广告 ID（例如：设置 → Google → 广告，或 设置 → 隐私 → 广告）。

3. 我们如何使用您的信息

我们自身不会使用您的个人信息。广告 SDK 处理的数据仅用于第 2 节所述的用途。

4. 我们如何共享您的信息

我们不会出售或共享您的个人信息。第 2 节所述的广告数据由 Google LLC 作为第三方服务商依据其自身的隐私政策进行处理。

5. 数据保留与删除

本应用不需要注册账号，因此不存在需要删除的账号数据。您的设置仅保存在设备本地，卸载应用或清除应用数据后即被删除。广告 SDK 收集的数据由 Google 依据其隐私政策保留，您可以通过第 2 节提到的广告 ID 设置限制其使用。

6. 本隐私政策的更新

我们可能会定期更新本隐私政策，更新后的隐私政策将通过应用内通知或更新版本告知您。请定期查看本隐私政策，以了解我们如何保护您的隐私。
